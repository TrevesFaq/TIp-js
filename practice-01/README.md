## Задание 1

Файл `js/hello.js` запущен двумя способами.
1. Node.js: команда `node practice-01/js/hello.js` из корня репозитория.
   Вывод появился в терминале. Последняя строка: `Тип document: undefined`.
2. Браузер: открыт `practice-01/index.html`, файл подключён через
   `<script src="./js/hello.js" defer>`. Вывод появился во вкладке console
   инструментов разработчика, на самой странице он не отображается.
   Последняя строка: `Тип document: object`.
Различие объясняется разницей сред выполнения. `document` - это программный доступ к загруженной странице.
Его предоставляет браузер, а не язык JavaScript. Node.js - среда выполнения
вне браузера, поэтому идентификатор `document` не
определён и `typeof` возвращает `"undefined"`.
